# Quantum Fractal System

This module implements a 14-dimensional cognitive vector space library for QRrune Cognitive Node using only C++20 standard library and SQLite3.

The 14 dimensions include:
- semantic_x
- semantic_y
- semantic_z
- temporal
- emotional_valence
- emotional_arousal
- abstraction
- confidence
- entropy
- cultural
- phonetic
- morphological
- radical_index
- usage_frequency

This README provides a high-level overview of the library functionality.
